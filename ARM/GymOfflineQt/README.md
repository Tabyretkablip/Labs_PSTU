# GymOfflineQt

Оффлайн приложение QtWidgets для учебного проекта: регистрация пользователя и разные кабинеты для администратора, тренера и клиента.

## Что есть в проекте

- Регистрация/вход по логину и паролю.
- Выбор роли: Администратор, Тренер, Клиент.
- Локальное хранение данных в `gym_data.json` рядом с exe-файлом.
- Администратор:
  - фиксация посещений;
  - списание групповых/персональных занятий;
  - аналитика: выручка, посещения, популярность занятий, отток клиентов;
  - контроль доступа по карте/QR или логину.
- Тренер:
  - график тренировок;
  - зал и оборудование;
  - замена, перенос и удвоение занятий;
  - индивидуальный час с клиентом.
- Клиент:
  - покупка и продление абонемента;
  - просмотр остатков занятий;
  - запись на групповые и персональные занятия.

## Сборка через Qt Creator

1. Откройте файл `GymOfflineQt.pro`.
2. Выберите kit:
   - Desktop Qt 5.12.12 MinGW 64bit, или
   - Desktop MSVC 64bit, если он установлен в Qt Creator.
3. Нажмите `Run qmake`.
4. Нажмите `Build` и `Run`.

## Важно

- Проект не использует базу данных и интернет.
- Для демонстрации сначала создайте тренера и клиента, потом заходите администратором и проверяйте вкладки.
- Если нужно очистить данные, удалите файл `gym_data.json` из папки сборки рядом с exe-файлом.
